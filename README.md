# Cloud Image Gallery

A beginner-friendly image gallery built with HTML, CSS, vanilla JavaScript, Node.js, Express, and AWS S3, intended for deployment on AWS EC2.

## Project structure

- `frontend/index.html` — gallery page and upload controls.
- `frontend/css/styles.css` — responsive page styling.
- `frontend/js/app.js` — browser-side upload, display, and delete interactions.
- `backend/server.js` — Express server and API routes.
- `backend/package.json` — backend metadata, dependencies, and start script.
- `backend/.env.example` — names of configuration values; put actual values in an ignored `.env` file.
- `backend/.gitignore` — excludes installed packages and local secrets from Git.

Setup and AWS deployment instructions will be added as the application is implemented.
